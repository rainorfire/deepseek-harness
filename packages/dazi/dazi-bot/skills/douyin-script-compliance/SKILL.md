# 抖音短视频文案合规与优化

## 触发条件

当用户出现以下任一请求时激活本技能：

- 给出一段文案，询问"是否会违反抖音社区自律公约"、"能不能审核通过"、"会不会限流"
- 让"优化"抖音/短视频文案
- 要"标题推荐"、"封面建议"
- 询问"短视频质量怎么样"、"节奏感如何"
- 题材涉及国际时政、地缘经济、区域发展、大国关系等敏感领域

## 核心工作流

处理抖音文案时，按以下顺序输出：

1. **合规评估**：逐条对照《抖音社区自律公约》，给出"能否过审 / 限流风险 / 人工复核 / 评论区引战"四维评估
2. **风险点标注**：具体指出敏感词、断言、数据来源、冲突表述
3. **脱敏优化版**：在不改变核心观点的前提下，替换敏感词、柔化判断、补充数据来源
4. **短视频节奏版**：改成短句、加画面提示、设计 3 秒钩子
5. **标题建议**：分稳妥型 / 悬念型 / 数据型，并标注应避开的敏感词

## 合规扫描清单

### 明确红线（一票否决）

文案若触碰以下任一项，直接判定无法审核通过：

- 反对宪法基本原则
- 危害国家安全、泄露国家秘密、颠覆国家政权
- 损害国家形象、荣誉和利益
- 煽动民族仇恨、破坏民族团结
- 违背宗教政策、煽动非法集会
- 丑化英雄烈士

### 高风险标签（大概率限流或人工复核）

- 直接点名他国军方、领导人"当选"合法性
- "战略价值"、"战略意义"、"战略命脉"、"咽喉"等地缘政治敏感词
- "大国"、"制衡"、"斡旋"、"停火"同时出现
- 对他国政权更迭、内部冲突做强势站队
- 未经权威来源的具体经济数据
- 强烈预测性断言："时间不多了"、"必须"、"必然"、"翻身仗"

### 数据合规要求

- 凡给出 GDP、人均 GDP、就业人数、项目投资额等具体数字，必须标注来源
- 优先引用 IMF、世界银行、新华社、外交部、联合国等权威来源
- 来源存疑或无法核实时，建议模糊化处理（"显著下降"、"大量岗位"、"可观收益"）

## 敏感词替换表（地缘政治题材）

| 原文表述 | 建议替换为 | 原因 |
|---|---|---|
| 极高的战略价值 | 具有积极意义 / 有助于降低物流成本 | 去"战略"标签 |
| 战略意义 | 积极意义 / 现实意义 | "战略"触发敏感模型 |
| 大国 / 大国博弈 | 多方 / 主要经济体 / 相关方 | 减少地缘对抗色彩 |
| 制衡本地区 | 保持自身空间 / 发展多元外交 | 去"制衡"敏感词 |
| 居中斡旋并促成停火 | 推动对话协商 / 建设性力量 | 弱化介入冲突的表述 |
| 军方、文人精英 | 各方 / 国内不同力量 | 避免阵营化 |
| 敏昂莱当选总统 | 缅甸领导人敏昂莱 | 不触碰政权合法性争议 |
| 翻身仗 | 发展机遇 / 翻盘机会 | 减少情绪化 |
| 时间不多了 / 迟疑 | 窗口期有限 / 关键在于自身决策 | 去紧迫感 |

## 节奏优化原则

- **3 秒钩子**：用数据冲突或问题开场，例如"人均 GDP 仅 1519 美元，却同时被中国和印度找上门？"
- **短句**：每句控制在 15-20 字以内，便于口播换气
- **一句一画面**：每个短句对应一个可视觉化的镜头或字幕
- **中段减速**：数据、项目罗列不要堆叠，每个项目只给 1 句话 + 1 个画面
- **结尾互动**：抛出一个开放性问题，引导评论区，但避免引战

## 标题策略

### 稳妥型（审核最安全）

- 缅甸的区位优势，能被它自己把握住吗？
- 一条印度洋出海口，能改变这个国家的经济命运吗？
- 从"陆锁国"到"陆联国"，缅甸还差什么？

### 悬念型（打开率较高）

- 为什么这个国家离中国这么近，却还没富起来？
- 印度洋边上这个国家，有机会靠一条铁路翻身吗？

### 数据型（增加可信度）

- 人均 GDP 约 1519 美元，缅甸还能翻盘吗？
- 东盟十国里最不发达国家之一，缅甸凭什么被看好？

### 标题应避开的词

战略、命脉、咽喉、博弈、大国、制衡、斡旋、停火、军方、翻身仗、时间不多了、必须

## 评估矩阵

| 风险项 | 低 | 中 | 高 |
|---|---|---|---|
| 无法审核通过 | 无红线、无站队 | 少量敏感词 | 触碰明确禁止项 |
| 限流 / 不推荐 | 经济化脱敏 | 保留"战略"等词 | 地缘冲突主导 |
| 人工复核 | 纯经济分析 | 政治人物 + 冲突 | 政权合法性争议 |
| 评论区引战 | 客观数据 | 涉及中印对比 | 直接站队某一方 |

## 输出格式

每次回复尽量包含：

1. 一句话结论（"大概率能过审，但有 X 风险"）
2. 风险点清单
3. 修改建议 / 优化版文案
4. 标题推荐（3-5 个）
5. 节奏建议（可选）
