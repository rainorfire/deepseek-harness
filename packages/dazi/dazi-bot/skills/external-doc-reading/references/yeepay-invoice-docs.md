## 【发票开具】数电票红字发票开具（快捷红冲）接口

- 开放平台：https://open.yeepay.com/docs/products/fwssfk/api/post__rest__v1.0__invoice__digit__fast-red
- 请求方式：POST `/rest/v1.0/invoice/digit/fast-red`，需签名验签，2025-06-11 更新
- 核心逻辑：已完成蓝字发票开具后想红冲时调用；若原蓝字发票**未被确认**，可直接开出红字发票（快速红冲）

| 参数 | 类型(长度) | 必填 | 说明 |
|------|-----------|------|------|
| reqId | string(40) | ✅ | 请求流水号 |
| merchantNo | string(11) | ✅ | 开票企业在易宝侧进件时的商编 |
| originalReqId | string(40) | ⚠️ 二选一 | 原蓝票请求流水号 |
| originalOrderNo | string(40) | ⚠️ 二选一 | 原蓝票开票单号 |
| digitalAccount | string(11) | ❌ | 电子税局登录账号（手机号） |
| callBackUrl | string(128) | ❌ | 开票结果回调地址 |

**两个关键坑：**
1. 调完本接口 ≠ 开票完成，必须再调【数电票开具结果查询】接口查结果。
2. 查询接口 `invoiceErrMsg` 返回「查询红票数电发票号码失败」时，需**再次**调用查询接口拿最终结果（异步，第一次可能没查到）。

**业务错误码（父码固定 40044）：**

| 子错误码 | 含义/处理 |
|----------|------|
| 0000 | 成功 |
| 0001 | 参数错误 → 改参数重提 |
| 1000~1005 | 服务商/商户/资质/税号关系/销方信息未维护 → 联系管理员 |
| 1103 | 未查询到数电账号信息 |
| 1105 | 该数电账号暂未登录 → 调登录接口 |
| 1300 | 当前操作需登录电子税局 |
| 2001/2004/2005/2006 | 发票服务未开通/开通失败/停用/到期 → 联系管理员 |
| 2002/3005 | 服务开通中/激活中 → 等待后查询 |
| 3001 | 发票服务未授权 → 先激活授权 |
| 9999 | 系统错误 → 联系易宝 |

**回调（易宝「结果通知机制」）关键字段：**

- `invoiceApplyStatus`：opening / success / fail
- `openType`：1-蓝票 / 2-红票
- `redChong`：unRed / allRed / reding
- `digitInvoiceNo`：数电发票号码
- `originalDigitInvoiceNo`：原蓝票号码（红票时才有值）
- `xmlUrl` / `pdfUrl` / `ofdUrl`：版式文件
- `invoiceDetailList`：明细行
- 附带 paymentList / paymentMerchantId：乐企联用字段
