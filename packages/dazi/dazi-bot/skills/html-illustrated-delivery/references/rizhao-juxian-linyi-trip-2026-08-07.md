# 案例：日照→莒县→临沂 3天自驾方案（2026-08-07）

佳哥在日照，8/8 自驾去临沂途经莒县，8/10 临沂高铁回长沙。交付「日照莒县临沂自驾方案.html」（281行，17.8KB）+ `方案图片/` 5张本地化图片，verification 代理 PASS。

## 关键数据（调研结论）

- **日照→莒县**：约76km / 1.2h，日兰高速，过路费25元+油费45元
- **莒县→临沂**：约79km / 1h41min，206国道为主（浮来中路→206国道→沂河大桥→临沂）
- **莒县**：浮来山65元（含定林寺，天下第一银杏树4000年）；莒县博物馆免费；莒国古城免费（19:30亮灯夜游）；世起羊肉汤
- **临沂**：孔庙（金代古建，千年银杏）；王羲之故居（书圣故里）；银雀山汉墓竹简博物馆（《孙子兵法》竹简，**周一闭馆**）；琅琊古城118元+《国秀·琅琊》98元起（19:30场，约60分钟）；糁汤早餐
- **老人友好**：每天≤2景点+午休；岳父70岁多数景区免票/半价；预算5人约3350元（不含高铁）

## 图片防盗链处理实录

1. 初版5张图全部用远端URL → chrome-devtools 验证只有浮来山（600px）加载成功，其余4张被防盗链拦截
2. 全部下载到本地改相对路径：孔庙/银雀山（新浪 sdnews）curl 直下成功；国秀·琅琊（携程）也成功
3. **琅琊古城携程图被拦成60x60小图**（防盗链）→ 弃用，改去官网 langyagucheng.com 抓图
4. 官网 OSS 图（omo-oss-image.thefastimg.com，4001×2000）**curl 直下返回29字节 `http 403` 文本**（Referer 签名校验）
   - 先用浏览器内 `fetch(url, {referrer:'http://www.langyagucheng.com/'})` 探测：返回 547KB 成功
   - 再 curl 加 `-H "Referer: http://www.langyagucheng.com/"` 重下 → 成功（4001×2000 高清）
5. `sips` 生成缩略图失败是因为文件是403文本不是图 → 先 `file` 确认再处理
6. 选图语义验证：查官网页 img alt（alt="琅琊古城" 的 154e36de 那张最合适）
7. 未用的候选图移入 `_候选图/` 子目录

## 渲染验证实录（chrome-devtools MCP）

- `new_page` 打开 `file://<绝对路径>`（注意中文路径需 URL 编码 %E6%97%A5...）
- evaluate_script 检查：`img.complete && img.naturalWidth > 0`
- **lazy loading 坑**：带 `loading="lazy"` 的图在首屏外不加载，检查误报失败 → `i.scrollIntoView()` + 等1.5s 再查 → 5张全过（600/1080/1080/4000/1080）
- 截图 base64 解码：`data['result']` 里 image 块索引不固定（本会话在 result[1]），遍历找 `type=='image'` 块
- 交付前 spawn verification 子代理（PASS）+ 手动抽查（ls/file/grep src 对应）

## 沉淀要点

- 旅游 HTML 方案的图片源优先级：**官网 > 新闻/攻略站 > 携程**（携程防盗链最狠）
- OSS 图 403 一律先试 `-H "Referer"`，别反复换参数碰运气
- `loading="lazy"` 验证必须滚动触发，否则假阴性
