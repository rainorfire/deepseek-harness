# 开票税收分类编码（中国）

## 是什么
税务总局《商品和服务税收分类与编码》国家标准（2017年修订后全国统一启用）。**开票时必须给每条开票明细挂一个税收分类编码**，否则税控端/电子税务局校验不过。

编码为 **19位 = 8位统一编码 + 11位扩展码**；前8位分：大类(1位)→中类(3位)→小类(2位)→细类(2位)。

## 同一张表，三个入口
| 入口 | 角色 |
|---|---|
| **电子税务局**（如湖南 https://etax.hunan.chinatax.gov.cn → 我要办税→发票使用→开票信息维护→商品和服务税收分类编码） | 权威源头，可按名称/编码检索，维护企业自定义编码 |
| **开票系统（税控盘/金税盘）** | 内置同表，开票下拉选择 |
| **第三方开票平台（百望/高灯/易宝）** | 平台侧同步维护，一般提供查询接口，进件/开票按编码传参 |

税务总局官网 https://www.chinatax.gov.cn 搜「商品和服务税收分类与编码」可下《2017年版》官方公告和附表。编码表**动态维护**，官方渠道永远最新。

## 关键规则：牌号不细分叶子，写进品名
编码表里柴油/汽油**不按牌号细分**。0号/-10号/-20号车用柴油、92/95/98号汽油**都挂同一个分类编码**，牌号只体现在开票品名（goodsName）里：

| 销售油品 | 品名栏填法 | taxCode |
|---|---|---|
| 0号车用柴油(VI) | `*柴油*0号车用柴油(VI)` | 柴油 107010103… |
| -10号车用柴油 | `*柴油*-10号车用柴油` | 同上 |
| 92号车用汽油(VI) | `*汽油*92号车用汽油(VI)` | 车用汽油 107010101… |
| 95号车用汽油(VI) | `*汽油*95号车用汽油(VI)` | 同上 |

**不要**尝试给每种牌号配不同编码——编码表里没有。

## 对接开票API（易宝/百望）
- `goodsName` 传 `*柴油*0号车用柴油(VI)` 这种完整品名（带星号包裹分类名）
- `taxCode` 传柴油/汽油分类编码

## 成品油数电票新规
成品油发票必须走**数电票平台的成品油项目/油品库存模块**，不能像普通商品随意开（2023-03-01 起成品油新规）。
