# 抖音短视频SRT字幕错别字纠正

## 默认路径

抖音短视频SRT文件的默认存储位置：
```
/Users/chenyujia/Movies/我的短视频/
```

**注意**：此Skill专用于处理抖音平台短视频的SRT字幕文件。

## 工作流程

### 1. 定位文件

根据用户提供的视频标题或文件名，在默认路径下查找对应的抖音短视频SRT文件。

**查找方式：**
- 如果用户提供完整路径：直接使用
- 如果用户提供视频标题：在 `/Users/chenyujia/Movies/我的短视频/` 下搜索匹配的文件夹或文件
- 文件名格式通常为：`{视频标题}.srt`

**注意**：此Skill仅处理抖音短视频SRT文件，不涉及其他平台或用途的字幕文件。

### 2. 读取内容

使用 `read` 工具读取SRT文件的全部内容，逐行检查字幕文本。

### 3. 识别错误

仔细阅读字幕文本，识别以下类型的错误：
- **错别字**：同音字、形近字错误（如"自制"应为"自治"）
- **用词不当**：不符合语境的词汇（如"避争地"应为"必争地"）
- **专有名词错误**：历史事件、条约、地名等（如"合约"应为"和约"）
- **断句问题**：缺少必要的标点断句
- **政治/历史术语**：确保使用准确的政治和历史术语

**⚠️ 换行处理规则（重要）**

- **换行造成的语义不连贯**：如果相邻两行因为换行导致语义不连贯（如"而不是现/在的半孤立"），但这属于字幕特有的断句节奏，**保持原样不变，不要擅自合并为一句**，因为这样会改变字幕的朗读节奏和时长
- **仅修正真正的错别字**：只有确认是错别字（如"拥核"写成"雍和"）才修正，对于换行造成的视觉上的"不流畅"不修正
- **前后文联系判断**：如果一行文本单独看有错别字，但联系下一行的开头或上一行的结尾能确认是换行导致的断字错误，应结合判断

### 4. 列出修改对照表

在修改前，向用户展示发现的错误列表：

| 序号 | 原文 | 修改后 | 位置/上下文 |
|------|------|--------|-------------|
| 1 | 错误内容 | 正确内容 | 所在行或上下文 |

### 5. 执行修正

- 使用 `write` 工具将修正后的内容写回原SRT文件
- 保持SRT文件格式完整（时间轴、序号、空行等）
- 确认文件保存成功

### 6. 完成汇报

向用户汇报：
- 共发现并修改了多少处错误
- 列出修改概要
- 确认文件已保存

## 抖音审核规范参考

纠正字幕时需确保内容符合《抖音社区自律公约》：

### 内容合规要求
- **客观中立**：客观陈述历史事实，不歪曲、不臆断
- **理性分析**：理性分析国际关系，不制造对立、不煽动情绪
- **尊重多元**：尊重各国发展道路，不贬低、不标签化
- **正向导向**：传播建设性观点，避免阴谋论和历史虚无主义

### 用词规范（东于人说标准）
| ❌ 禁用 | ✅ 改用 |
|--------|--------|
| 棋子 | 面临挑战 |
| 附庸 | 探索道路 |
| 傀儡 | 不同选择 |
| 困境 | 寻找平衡 |
| 衰落 | 适应变化 |

**原则**：禁用贬低/过度负面词汇，改用中性/正向表述

## 常见错误类型参考

### 地缘政治类视频常见错误
- 政治术语："制衡"误为"军事制衡"、"均势原则"误为"军事原则"
- 历史术语："和约"误为"合约"
- 地理术语："必争之地"误为"必征之地"等

### 中文用词规范
- 避免使用贬义词汇（遵循东于人说文案规范）
- 确保历史专有名词准确（条约名、战役名、人名等）
- 注意同音字区分（如"做"vs"作"、"的"vs"地"vs"得"）

## 注意事项

1. **🚨 严禁修改时间轴**：绝对不能修改任何时间戳，包括开始时间、结束时间、字幕序号。时间轴是字幕的骨架，修改后会导致音画不同步
2. **保持格式**：SRT格式必须严格保持（序号、时间轴、文本、空行）
3. **时间轴不变**：只修改文本内容，不调整时间轴
4. **备份意识**：虽然直接覆盖原文件，但应确保修改准确
5. **用户确认**：重大修改前可先列出对照表供用户确认
