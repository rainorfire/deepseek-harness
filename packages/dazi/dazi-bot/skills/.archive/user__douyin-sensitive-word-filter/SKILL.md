# 抖音敏感词检测与替换

## 重要前提

⚠️ **使用此skill前，必须先向用户询问敏感词检测接口的curl地址**

此接口需要登录认证（含cookie），无法预置。每次使用前，请询问用户：
> "请提供敏感词检测接口的curl命令（含登录后的cookie）"

## 工作流程

### 1. 获取接口信息

向用户询问：
- 敏感词检测接口的完整curl命令
- 或接口URL和必要的认证信息

**必须包含：**
- 接口URL
- 请求方法（POST/GET）
- Headers（特别是Cookie，用于登录认证）
- 请求参数格式

### 2. 调用接口检测敏感词

使用用户提供的curl命令调用接口，传入待检测文案。

**接口调用示例格式：**
```bash
curl 'http://www.example.com/api/check' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -H 'Cookie: xxxxxx' \
  --data-raw 'text=待检测文案'
```

### 3. 解析返回结果

接口通常返回以下信息：
- **高亮标记的敏感词**：用HTML标签标注（如 `<span style="background-color:#f0ba28;">敏感词</span>`）
- **不可使用的违禁词**：通常标记为红色或特殊标识
- **敏感词类型**：通用违禁词、政治敏感词等

**解析要点：**
- 提取所有 `background-color` 高亮的词汇
- 区分不同颜色标记的风险等级
- 记录违禁词的ID和类型

### 4. 替换敏感词

将检测到的敏感词，**首字替换为拼音首字母大写**：

| 原词 | 拼音 | 替换后 |
|------|------|--------|
| 俄罗斯 | éluósī | **E**罗斯 |
| 中心 | zhōngxīn | **Z**心 |
| 专制 | zhuānzhì | **Z**制 |
| 自由 | zìyóu | **Z**由 |
| 民主 | mínzhǔ | **M**主 |
| 亡国 | wángguó | **W**国 |
| 希特勒 | xītèlè | **X**特勒 |
| 大陆 | dàlù | **D**陆 |
| 分裂 | fēnliè | **F**裂 |
| 革命 | gémìng | **G**命 |
| 基督教 | jīdūjiào | **J**督教 |
| 领导人 | lǐngdǎorén | **L**导人 |
| 第二 | dìèr | **D**二 |
| 最 | zuì | **Z** |

### 5. 生成修改后的文案

将替换后的文本整理成完整文案，保持原文结构和格式。

### 6. 返回结果

向用户返回：
- 检测到的敏感词列表
- 替换对照表
- 修改后的完整文案

## 使用示例

**用户请求：**
> 帮我检测这篇文案的敏感词

**系统询问：**
> 请提供敏感词检测接口的curl命令（含登录后的cookie）

**用户提供：**
```bash
curl 'http://www.ju1.cn/Index/add' \
  -H 'Cookie: PHPSESSID=xxx; ju1cookie=xxx' \
  --data-raw 'text=待检测文本'
```

**系统执行：**
1. 调用接口检测
2. 解析返回的高亮敏感词
3. 按规则替换首字母
4. 返回修改后的文案

## 注意事项

1. **🚨 严禁修改时间轴**：如果处理的是SRT字幕文件，绝对不能修改任何时间戳，包括开始时间、结束时间、字幕序号。时间轴是字幕的骨架，修改后会导致音画不同步
2. **必须先获取接口**：没有用户提供的curl命令无法执行检测
3. **cookie会过期**：提醒用户如果接口返回登录失效，需要重新获取curl
4. **仅替换首字**：保持词汇辨识度，同时规避检测
5. **保留原文结构**：替换后保持段落、标点、格式不变
6. **区分风险等级**：红色高亮（#f95647）通常为违禁词，必须替换；黄色高亮（#f0ba28）为敏感词，建议替换
