# 飞书图片发送：用户身份发送流程

## 用户明确要求

- `--as bot` 身份发送显示为「Claude claw」，**用户（佳哥）明确要求不要用 bot 直发**
- 正确做法：两步法，最终以 `--as user` 身份发送（显示为「陈宇佳」）

## 图片发送两步法（已验证）

```bash
# Step 1: bot 上传本地图拿到 image_key
lark-cli im images create --data '{"image_type":"message"}' --file image=<本地图片路径> --as bot

# Step 2: user 身份用 image_key 发送
lark-cli im +messages-send --as user --user-id <openId> --image <image_key>
```

## 授权范围

发送图片需要以下 scope：
- `im:message.send_as_user`（发消息）
- `im:resource:upload`（上传图片资源）
- `im:resource`（资源访问）

## 注意事项

- Step 1 必须用 `--as bot`，只有 bot 身份支持上传图片
- Step 2 用 `--as user`，不能直接传本地路径，必须传 image_key
- 用户身份直传本地图会报 missing_scope 错误（im:resource:upload + im:resource）
- 当前 lark-cli 配置的是 Claude Code 的 bot app（cli_a9f04918dcf89ceb），如有搭子 bot 的 app_secret 可加 profile
- 图片发送后显示为「陈宇佳」发给自己的消息
