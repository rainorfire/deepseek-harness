# 教师文档分析

## 触发条件

用户要求分析/处理/提取/转换以下教学类文档时触发：
- 期末/期中试卷（PDF 或图片）
- 成绩表、素养测评表（图片）
- 教辅资料、练习题（PDF/图片）
- 教案、听课记录、教研材料（PDF/Word）

## 核心流程

### 1. 判断文档类型

| 情况 | 判断方法 | 处理方式 |
|------|---------|---------|
| 文本型 PDF | `page.get_text()` 能提取到完整文字 | 直接读取/提取文本 |
| 扫描/图片型 PDF | `page.get_text()` 只有页码或空白 | 必须 OCR |
| 单张图片 | 用户直接发送图片 | 直接读取或 OCR |
| 倾斜/模糊图片 | 文字识别困难 | 先校正再 OCR |

### 2. 文本型 PDF 处理

- 使用 PyMuPDF (`fitz`) 读取文本和页面结构。
- 如需保留图片与排版，按 Y 坐标排序文本块和图片块，混合渲染到 Word/HTML。
- 参考 DAZI.md 规则：填空括号用正则替换为宽空格版本；过滤孤立字符和页脚。

### 3. 图片/扫描型 PDF 处理

1. **先安装 OCR 工具**（如未安装）：
   ```bash
   brew install tesseract tesseract-lang
   ```
2. **PDF 转图片**：用 PyMuPDF 按 `dpi=200` 渲染，尺寸控制在 `2000×2000` 以内（Read 工具限制）。
3. **分块读取**：若一页包含两栏/两面，按中线裁切后再用 Read 识别。
4. **OCR 识别**：可调用 `pytesseract` 或 `paddleocr`（中文表格优先 PaddleOCR）。
5. **结果校验**：对关键数字（分值、页码、题号）做人工核对。

### 4. 试卷分析模板

当用户要求“试卷分析”时，按以下三维度输出：

#### 4.1 试题结构和分值

| 题型 | 题量 | 分值 | 占比 |
|------|------|------|------|
| 填空题 | X 题 | X 分 | X% |
| 选择题 | X 题 | X 分 | X% |
| 计算题 | X 题 | X 分 | X% |
| 操作/作图题 | X 题 | X 分 | X% |
| 解决问题 | X 题 | X 分 | X% |
| **合计** | — | **100 分** | **100%** |

#### 4.2 知识点及难度评估

| 知识模块 | 对应题号 | 核心考点 | 难度 |
|---------|---------|---------|------|
| ... | ... | ... | 基础/中等/较难 |

- 难度分层：基础（直接考查概念/公式）、中等（需一次转化或综合 2 个知识点）、较难（空间想象/最优策略/多步推理）。

#### 4.3 学情分析

1. **掌握较好的点**：列出学生普遍能拿分的模块。
2. **常见失分风险点**：按题号列出易错点、可能错误。
3. **教学/复习建议**：给出 3-5 条可执行建议。
4. **总体评价**：用一句话总结试卷质量和预期分数段。

## 避坑要点

- **Read 工具图片限制**：超过 2000×2000 像素会失败，渲染前先限制尺寸。
- **扫描版 PDF 不要直接 `get_text()`**：会误以为 PDF 是空白的。
- **OCR 安装优先 tesseract + chi_sim**：若无系统 tesseract，尝试轻量 OCR 库。
- **试卷分值要逐项核对**：尤其注意“每空 1 分/每题 2 分”等细节。
- **先确认页数**：扫描版试卷可能把两页拼成一张图，需先裁切。
